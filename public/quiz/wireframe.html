无障碍 & 国际化 / A11y & i18n

Compliance Notes
无障碍 / Accessibility
✓ aria-live="polite" — quiz-shell 动态内容
✓ aria-live="assertive" — feedback 即时播报
✓ role="group" — options 容器
✓ alt text — 每张 diagram 图片
✓ focus ring — outline 2px accent
✓ keyboard nav — Tab 顺序与视觉一致
✓ 44×44px — 最小触控目标
✓ 4.5:1 — 文字对比度最低要求
✓ cursor:pointer — 所有可点击元素
✓ disabled state — opacity:0.45 + cursor:not-allowed
国际化 / i18n Keys
title · subtitle
progressLabel · levelLabel · questionLabel
next · restart · loading
incorrect · finished · doneHint
题目文字由 quiz.js 直接注入，
不使用 data-i18n 属性（防止 i18n 异步覆盖）。
语言切换时保持当前题目状态不重置。
